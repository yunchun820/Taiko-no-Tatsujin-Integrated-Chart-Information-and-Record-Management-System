# TTICIRMS

태고의달인 통합 채보 정보 및 기록 관리 체계 (Taiko no Tatsujin Integrated Chart Information and Record Management System)

태고의 달인 채보 정보와 내 기록을 한곳에서 보는 안드로이드 앱의 배포 저장소입니다. 이 저장소에는 설치 파일(APK)과 업데이트 기록만 올라갑니다.

## 설치

1. [Releases](../../releases/latest)에서 `TTICIRMS-vX.apk`를 내려받습니다.
2. 내려받은 파일을 열고, 처음이면 "출처를 알 수 없는 앱" 설치를 허용합니다.
3. Play 프로텍트가 경고하면 "자세히"에서 "무시하고 설치"를 고릅니다.

## 업데이트

앱의 설정에서 `앱 업데이트 확인`을 누르면 이 저장소의 최신 릴리스를 확인하고 바로 설치합니다. 새 버전이 나오면 알림도 오며, 설정의 `업데이트 알림`에서 끌 수 있습니다.
